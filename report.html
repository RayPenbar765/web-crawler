ONE-TIME SETUP

처음 한 번 환경을 준비하세요

Python 3.10 이상과 Node.js 18 이상이 필요합니다. 설치는 Python 패키지, Chromium, agent-browser, 사전 검증 순서로 진행됩니다.

Windows · PowerShell

powershell -ExecutionPolicy Bypass -File scripts\setup.ps1

macOS · Linux

python -m venv .venv && . .venv/bin/activate && python scripts/bootstrap.py

설치가 막히면 README의 설치 안내를 확인하세요. core만 통과하고 agent-browser가 실패하면 전체 설치는 미완료입니다. ChatGPT Work 클라우드는 로컬 브라우저와 세션을 상속하지 않아 전체 파이프라인에 적합하지 않습니다.

HOW IT WORKS

한 번 정찰하고, 다음에는 기억합니다

같은 사이트를 다시 수집할 때는 저장된 프로필을 먼저 확인해 정찰을 줄입니다. 수집 성공 후에는 프로필을 저장하거나 갱신합니다.

요청 분석→프로필 확인→필요 시 정찰→수집·검증→프로필 저장→엑셀 보고

공개 API 등 이용 가능한 경로가 있으면 이를 활용합니다. 정찰은 agent-browser가 표준이며, 실제 수집은 생성된 스크립트에서 Scrapling 또는 Playwright로 수행합니다.

BEFORE YOU COLLECT

수집 전에 확인할 점

  • 사이트의 이용 조건과 robots.txt, 요청량, 데이터의 성격과 사용 목적을 확인하세요.
  • 자동 접근 차단이나 대상 경로의 robots.txt 제한을 만나면 에이전트가 알리고 진행 여부를 묻습니다.
  • 로그인은 사용자가 직접 합니다. ID와 비밀번호는 코드나 파일에 저장하지 않습니다.
  • 개인정보가 감지되면 경고·보고하며, 수집 결과가 0건이면 중단합니다. 요청량 상한은 필요에 맞게 지정하세요.

세부 규칙과 이용 범위는 저장소의 README와 ACCEPTABLE_USE.md에서 확인하세요.
